# SkillForge - AI-Powered Career Development Platform

A personal AI portfolio project developed completely by **Arunima Sadhukhan**.

## 📝 Key Features
* **AI Career Advisor**: Analyzes skills and suggests personalized career paths.
* **Skill Gap Analysis**: Identifies what skills you need for your dream job.
* **Resume Optimization**: Uses AI to enhance resumes for applicant tracking systems.
